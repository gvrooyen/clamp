# Private Clamp knowledge repository

- The remote `origin/main` tip is the only durable knowledge authority.
- Knowledge concepts live only under `knowledge/`; `TODO.md` is generated by
  `kb todo` and must never be edited manually.
- Always invoke `kb` with `--repo /home/user/workspace/repo`.
- The CLI and authoritative migrations come from the x86-64 public runtime
  pinned by `.agents/clamp-runtime.lock`. Never add or build implementation
  source in this private repository.
- Never print connection URLs or secret values. Production migration, sync,
  publication, and paid embedding calls require explicit user authorization.
- Preserve unknown OKF frontmatter keys. Explicit user claims normally use
  `clamp.asserted_by: human:owner`; agent-authored content normally uses
  `generated.by: amp/agent`.
- Change the runtime only by reviewing all four lock fields, running
  `.agents/setup`, and validating the private bundle before committing the
  lock update.
- Keep private knowledge, personal identifiers, credentials, and operational
  evidence out of the public Clamp repository.
